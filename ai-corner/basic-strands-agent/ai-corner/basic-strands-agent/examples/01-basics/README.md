# 01-basics: Getting Started

Start your Strands journey here! These are the simplest examples.

## Files

### plugin-basics.py ⭐ **START HERE**
- **What:** Use a built-in plugin (ContextInjector)
- **Learns:** How plugins work, basic agent setup
- **Time:** 5 minutes
- **Run:** `python plugin-basics.py`

### basic-agent-bedrock.py
- **What:** Create agent with tools and hooks
- **Learns:** Tools, hooks, event handling
- **Time:** 10 minutes
- **Run:** `python basic-agent-bedrock.py`

## Concepts Learned

- ✅ Creating an agent
- ✅ Using built-in plugins
- ✅ Adding tools
- ✅ Registering hooks
- ✅ Basic event handling
