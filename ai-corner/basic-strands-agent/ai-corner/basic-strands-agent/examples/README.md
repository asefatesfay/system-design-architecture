# Examples Directory

Examples organized by topic in progressive difficulty.

## 📚 Learning Path

Follow folders in order:

1. **[01-basics/](01-basics/)** - Start here! Basic plugins and agents
2. **[02-custom-plugins/](02-custom-plugins/)** - Build your own plugins
3. **[03-skills/](03-skills/)** - Specialized instructions
4. **[04-hooks/](04-hooks/)** - Direct event handling
5. **[05-session-management/](05-session-management/)** - Persist conversations

---

## Quick Access

### Absolute Beginner? Start Here:
```bash
cd 01-basics
python plugin-basics.py
```

### Want to Build Plugins?
```bash
cd 02-custom-plugins
python custom-plugin-basics.py
```

### Need Skills?
```bash
cd 03-skills
python skills-basics.py
```

### Session Management?
```bash
cd 05-session-management
python learn_session_management.py
```
